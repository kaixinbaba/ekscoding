# Logic Map Numbering

编号用于稳定引用业务逻辑。编号一旦被其他文档、Issue、PR 或 Agent 任务引用，**不得**随意重命名或重排。

## 核心原则

- **编号不复用。** 已删除的编号永久空缺，新内容使用新编号。复用旧编号会导致历史引用（Issue、PR、Agent 任务）指向错误的业务逻辑。
- **编号稳定。** 拆分、迁移、补充新内容时，已有编号保持不变。新增内容使用当前模块最大编号 +1。
- **编号唯一。** 同一模块内每个编号只对应一个页面/API/Action/流程。二级编号 `Xn.m` 在模块内唯一。

## 顶层模块

| 前缀 | 模块 | 说明 |
| --- | --- | --- |
| A | 全局骨架 | 路由、i18n、布局、Provider、配置、权限分层 |
| B | 公共页面 | 首页、营销页、定价页、法务页、公共表单 |
| C | 认证账户 | 登录、注册、OAuth、邮箱、密码、会话、账户安全 |
| D | 工作台 | Dashboard、Settings、Admin、API Keys、用户后台 |
| E | 商业闭环 | 支付、订阅、一次性购买、积分、webhook、账单 |
| F | 内容与接口集成 | Blog、Docs、搜索、上传、邮件、通知、newsletter、Cron/API |

> 实际项目如果超出 A-F 范围，可在生成时按需扩展 G、H 等新模块。

## 文档层级

逻辑地图采用两层文档结构：

```
docs/logic-map/
├── A-global-routing.md          ← 模块索引页（顶层）
├── A-global-routing/             ← 二级文档目录
│   ├── routing-i18n.md
│   ├── layouts-providers.md
│   ├── permissions-actions.md
│   └── config-flags.md
├── B-public-pages.md             ← 模块索引页
├── B-public-pages/               ← 二级文档目录
│   └── ...
```

- **模块索引页**（如 `A-global-routing.md`）：只保留模块总览、编号段分配表、二级文档链接和简要摘要。不展开具体流程。
- **二级文档**（如 `routing-i18n.md`）：承接一个业务子域的具体流程，包含完整的入口表、调用顺序、流程图、异常边界和维护清单。

### 阅读路径

根索引 → 模块索引页 → 二级文档。修改业务前，**必须**追踪到对应的二级文档理解调用链路。

## 模块索引页编号

模块索引页使用 `X` 级编号段，负责声明本模块所有二级文档的编号分配：

| 编号 | 含义 | 使用位置 |
| --- | --- | --- |
| `X0` | 模块总览 | 模块索引页 |
| `X1`-`X9` | 编号段范围声明 | 模块索引页，每段对应一个二级文档 |

模块索引页中的 `X1`-`X9` 不再展开具体表格，只声明该编号段分配给哪个二级文档。

## 二级文档编号（Xn.m）

二级文档内部使用 `Xn.m` 三级编号：

| 编号 | 含义 |
| --- | --- |
| `Xn.0` | 该子域总览 |
| `Xn.1` | 页面/API 入口表 |
| `Xn.2` | 用户动作与服务端入口 |
| `Xn.3` | 数据、状态和配置 |
| `Xn.4` | 主流程图（Mermaid） |
| `Xn.5` | 异常、权限和边界 |
| `Xn.9` | 维护注意事项 |

`X` 为模块前缀，`n` 为二级文档在模块内的序号（1-9），`m` 为文档内条目序号。

`Xn.m` 只在当前模块内唯一。不同模块可以有相同的 `n.m`（如 A1.1 和 B1.1 不冲突）。

## 新增内容归档规则

### 新增页面

1. 判断页面所属模块。
2. 在模块索引页找到对应二级文档。如果不能归入已有二级文档，判断是否需要新增二级文档。
3. 在二级文档的 `Xn.1` 表追加新行，使用该文档当前最大 `m` +1。

### 新增顶层模块

只有同时满足以下条件才新增顶层模块（前缀 G、H…）：
- 横跨多个页面和服务端入口
- 有独立的用户入口和使用场景
- 不属于现有模块的业务边界
- 有独立的生命周期（创建、使用、销毁）

## 删除规则

- 删除功能时，**保留编号**，在原位置标记 `[已移除]`，写明移除日期和替代入口。
- 删除整个二级文档时，在模块索引页的编号段分配表中标记该文档为 `[已移除]`，保留 `n` 序号不回收。
- **严禁**将新内容填入已删除编号。新内容必须使用新编号。

## 交叉引用格式

二级文档之间的交叉引用使用 `模块前缀 + 编号` 格式：

- 同模块内：`参见 A3.2`
- 跨模块：`由 E3.1 触发，结果写入 E9.3`
- 模块索引页：`详见 A-module routing-i18n.md`

引用编号而非页码或文件名，确保文档重命名后引用仍然可追踪。
